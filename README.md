# Medical.MyAIworker.online

Static GitHub Pages site for **Morgan**, the premium AI medical administrator
for doctors, dentists, and chiropractors.

- Limited-time implementation: **$2,500 through September 7, 2026**
  (regularly $5,000).
- Recurring service: **$1,500/month for the first user** plus **$1,000/month for
  each additional user**.
- The first recurring invoice is sent 30 days after go-live.
- Service is month-to-month.
- This website intentionally contains no public monthly-service payment link.

## Privacy and compliance language

The site describes safeguards that can support HIPAA-conscious deployment. It
does not promise that one tool automatically makes a practice HIPAA compliant.
The complete deployment must account for vendor eligibility and agreements,
access, integrations, policies, training, risk assessment, and human oversight.

## Deployment

Static site with no build step. Publish the project root through GitHub Pages
using the custom domain in `CNAME`.
